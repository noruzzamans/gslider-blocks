# 🎠 GSlider Blocks Design System

Welcome to the **GSlider Blocks Component Library & Storybook**, engineered to provide an isolated development environment for our 23 reusable Gutenberg UI controls.

---

## 🏛️ Architecture & Principles
- **Gutenberg Inspector Aligned**: Every control is built specifically for the WordPress Block Inspector sidebar (280px–300px width).
- **Responsive-First Architecture**: Seamlessly handles Desktop, Tablet, and Mobile device settings.
- **Pure React & Zero Bloat**: No legacy jQuery dependencies.
- **Model-Agnostic & MCP-Ready**: Synchronized with our Model Context Protocol (MCP) server schemas.
