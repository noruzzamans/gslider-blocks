# 🎠 GSlider Blocks Design System

Welcome to the official **GSlider Blocks Component Library & Storybook**, modeled directly after the [WordPress Gutenberg Storybook](https://wordpress.github.io/gutenberg).

---

## 🏛️ Architecture & Principles
- **Gutenberg Inspector Aligned**: Every control is built specifically for the WordPress Block Inspector sidebar (280px–300px width).
- **Responsive-First Architecture**: Dedicated 3-device controls (Desktop, Tablet, Mobile) with synchronized state.
- **Pure React & Zero jQuery**: Lightweight modern React components.
- **Model-Agnostic & MCP-Ready**: Synchronized with our Model Context Protocol (MCP) server schemas.
